Codex Auto Retry 0.7.1 - Windows x64 安装说明
================================================

适用环境
--------
- Windows 10/11 64 位
- 电脑上已经安装并至少启动过一次 Codex App
- 不需要管理员权限
- 不需要安装 Go、Node.js 或其他开发工具

安装
----
1. 先把整个 ZIP 解压到一个普通文件夹，不要直接在压缩包预览窗口里运行。
2. 双击“安装.cmd”。
3. 等待窗口显示“Installation succeeded”。
4. 安装后会出现独立的 Codex Auto Retry 托盘图标。双击图标可打开设置。
5. 完整退出并重新启动一次 Codex App，使 Codex 接入共享后台恢复通道。
6. 在 Codex App 中新建一个任务，即可加载内嵌管理面板。

自动重试在安装后是全局生效的，不需要在每个任务里引用插件，也不需要一直
打开管理面板。后台守护进程和托盘图标会随当前 Windows 用户登录而启动，不会获得管理员
权限。安装或升级不会删除已有的重试文字、暂停状态、队列、历史状态和日志。

托盘设置
--------
双击托盘图标可以查看任务倒计时和队列，并分别设置“本次故障恢复”上限
（默认 15 次）和“连续无进展”上限（默认 5 次），还可以选择固定间隔、等差
递增或翻倍递增等待，并设置首次/固定、每次增加与最大等待时间。达到任一上限后，
该任务会停止自动尝试，也可以在列表中选择“重新开始”。
“本次故障恢复”最多可设为 1000 次，“连续无进展”最多可设为 100 次。
托盘中的通知开关只控制插件达到重试上限时发出的提醒。Codex 自己显示的
“ChatGPT finished a turn”轮次完成提醒，需要在 Codex 的“设置 > 常规 > 通知 >
轮次完成通知”中选择“从不”；这也会同时关闭正常完成任务的提醒。

管理面板
--------
在 Codex 中输入“打开 Codex Auto Retry 管理面板”，可以查看倒计时、任务队列、
暂停开关、两种重试上限和等待策略，并修改后备重试文字。普通对话会先在原任务中
静默续接，不新增用户消息，也不会回滚并重发原请求；只有 Codex 明确不支持静默
续接时才会发送后备文字。目标模式使用 Codex 原生目标恢复，不会发送这段文字。

插件也会识别供应商返回 HTTP 200、但模型没有产生最终回复的“空响应”，并按相同的
双重次数上限和等待规则自动重试。产生可见回复或工具结果后，“连续无进展”会
重新从 1 计算，但“本次故障恢复”继续累计，避免恢复循环无限运行。用户取消当前
轮次或暂停目标时，自动重试会停止。

目标暂停保护
------------
如果用户或 AI 主动暂停目标（包括等待用户验收），插件会取消该目标正在倒计时或
启动中的自动恢复。只有目标后来被明确恢复为运行状态，才会重新允许目标本身恢复。
如果目标暂停后用户又主动发送了一条普通消息，这条消息遇到供应商故障时可以独立
静默重试，但目标仍保持暂停；如果暂停发生在该消息开始之后，则同样取消重试。插件
不会根据聊天正文里的关键词猜测是否需要继续。

卸载
----
双击“卸载.cmd”即可停止后台进程、恢复安装前的共享服务环境值、移除开机启动
和 Codex 插件。默认会保留重试设置、状态和日志，重新安装后可以继续使用。

如需彻底删除这些数据，可在本文件所在目录打开 PowerShell 后运行：

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall-release.ps1 -RemoveData

安装位置
--------
- 插件文件：%USERPROFILE%\plugins\codex-auto-retry
- 运行程序和状态：%LOCALAPPDATA%\CodexAutoRetry
- Codex 插件缓存：%USERPROFILE%\.codex\plugins\cache
- 当前用户开机启动项：CodexAutoRetry

安全与校验
----------
安装程序会先按 SHA256SUMS.txt 检查发布包里的每个文件，再执行安装。外层 ZIP
的哈希值写在同目录的 .sha256.txt 文件中。程序不会读取或保存 API 密钥、消息
正文、工具参数或回复正文。

当前发布包未使用商业代码签名证书，因此 Windows 或安全软件可能显示“未知发布
者”。请只使用来源可信且 SHA-256 一致的发布包。

排查
----
- 安装器提示找不到 Codex：先启动一次 Codex App，然后重新双击“安装.cmd”。
- 后台状态日志：%LOCALAPPDATA%\CodexAutoRetry\logs\daemon.log
- 安装完成后看不到插件：在 Codex App 中新建一个任务；旧任务不会重新加载插件。
- 托盘显示“请重启一次 Codex”：完整退出并重新打开 Codex，等待中的任务会自动恢复。
- 永久失效或被撤销的账号仍需要重新登录，自动重试不会绕过身份验证。
