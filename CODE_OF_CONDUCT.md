# Code Of Conduct

We want this project to be useful, technical, and welcoming. Participants are
expected to communicate respectfully, assume good faith, and focus criticism on
the work rather than on people.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disclosure of private information, and attempts to expose
credentials or conversation data. Security reports must use the private process
in [SECURITY.md](SECURITY.md), not a public issue.

Project maintainers may edit, close, or remove contributions that violate this
standard. For a conduct concern, contact the maintainer through the public
GitHub profile at <https://github.com/sybxxx> with the repository and context.
