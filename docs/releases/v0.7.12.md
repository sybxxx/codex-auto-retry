## Codex Auto Retry v0.7.12

### Recovery Fixes

- Decoupled verified official IPC recovery from the optional shared-backend switch. Supported Codex Desktop builds can retry through their official route even when shared mode is disabled or unhealthy.
- Added guarded requeueing for recent retries stopped before dispatch because the shared backend was disabled. The existing retry budgets and recovery deadline are preserved. User cancellation, new turns, active work, expired chains and ambiguous dispatches prevent automatic reopening.
- Preserved official IPC readiness across configuration reloads and successful recovery actions.

### Retry Limits and Status

- Added an editable **Auth Error Limit** to both the Windows settings window and embedded panel, and to the settings API. The default remains 6; the supported range is 1-1000. Both global limits still apply.
- Authentication-specific exhaustion now has a distinct stop reason. Temporary `auth_unavailable` errors continue to use the global limits.
- Fixed historical attempt counts being reduced when an error changes category or a limit is lowered. A display such as `19/6` now preserves the 19 attempts made before the lower ceiling became applicable. Previously truncated records are not reconstructed.

### Installer Reliability

- Fixed Windows PowerShell 5.1 treating CLI stderr warnings as failures despite a successful exit code. Output streams are captured separately with bounded size and time limits.
- Added pre-install plugin-list checks and exact installed-version verification. Error messages report exit codes and safe categories without logging raw output or credentials.
- Extended failed-upgrade rollback to restore plugin and runtime files together, with checksum checks, startup-state safeguards and retained recovery journals when rollback is incomplete. Retry data is preserved and the previous worker is not automatically restarted.
- The one-click installer now offers a Chinese **Retry / Cancel** prompt while Codex is running. Save your work, fully exit Codex, then click Retry. Cancellation or timeout exits cleanly without replacing installed files; the installer never force-closes Codex.

### Installation

Download and extract `Codex-Auto-Retry-0.7.12-windows-x64.zip`, then run `安装.cmd`.
The package includes the startup manager, safe launcher and emergency-disable tools. No Go or Node.js installation is required.

Shared-backend mode remains opt-in, and the installer never publishes a global `CODEX_APP_SERVER_WS_URL` route. Existing retry settings are retained; installing this release does not increase the authentication retry limit automatically.

Regression coverage includes IPC transport recovery, retry budgets, native settings save, CLI warnings and timeouts, cancellation prompts, and isolated upgrade/rollback scenarios. Real provider availability and a full reboot remain outside automated release validation.
